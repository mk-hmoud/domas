Enhanced Location Management and Selection:

- Implemented a unified selection system that synchronizes state between the Location Tree and the Detail view.
- Added a "Select Branch" feature to the location tree, allowing recursive selection of a node and all its descendants.
- Refactored bulk deletion and edit logic to support selections from both the tree and the card list simultaneously.
- Improved UI polish by centering empty state messages and ensuring consistent layout.
- Added specific success/error notifications for location deletion in English and Turkish.

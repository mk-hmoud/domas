Room catalog: redesign ApplyPage into 5-step funnel.

The accommodation application flow is now:

1. **Semester** — pick the target semester (unchanged)
2. **Preferences** — optionally filter by building and/or room capacity (1–8 beds)
3. **Room Type** — browse a catalog of room types with hero photos, descriptions, amenity badges, available-bed counts and price range; tap a card to pre-filter beds, or skip with "Browse all beds"
4. **Bed** — existing location drilldown, now pre-filtered by the chosen room type (or unfiltered if skipped); shows a "Showing beds in: <type>" hint when filtered
5. **Review & Submit** — summary now includes the chosen room type if one was selected

The desktop sidebar and mobile stepper both reflect all five steps.
